# 24 - Prompt Kütüphanesi (Prompt Library)

## 📚 Platform İçi Tüm Prompt Kataloğu

1. **Master System Prompt**: AI Asistanının genel kimliği ve anti-hallucination kuralları.
2. **ML Interpretation Prompt (`ml.ts`)**: ML tahmin ve anomali çıktılarını iş diline çeviren prompt.
3. **Executive Summary Prompt**: Yönetici özeti oluşturan prompt.
4. **KPI Explanation Prompt**: KPI ihlallerini açıklayan prompt.
